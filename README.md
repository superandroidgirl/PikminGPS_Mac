# PikminGPS Web — macOS iOS GPS 模擬器

在瀏覽器中操控 iPhone 的 GPS 定位，支援傳送、搖桿移動、路線行走、OSRM 導航、GPX 匯入與 Pikmin Bloom 金盆模式。

## 系統需求

| 項目 | 最低需求 |
|------|---------|
| 作業系統 | macOS 11 Big Sur 或更新（Apple Silicon / Intel 皆可） |
| iPhone | iOS 14 以上 |
| 連線方式 | USB Lightning / USB-C 線，或同一 WiFi 網路 |
| 瀏覽器 | Safari / Chrome / Firefox（任一現代瀏覽器） |

> iOS 17 以上裝置需要 tunneld 通道——介面內提供按鈕一鍵啟動，**不需要終端機**。

## 安裝（DMG 一鍵安裝）

1. 下載 **`PikminGPS.dmg`**
2. **雙擊** DMG 檔案掛載
3. 將 **PikminGPS** 圖示**拖到 Applications 資料夾**
4. 退出 DMG（在側邊欄按右鍵 → 退出）
5. 從 **啟動台 (Launchpad)** 或 Applications 開啟 PikminGPS

### 第一次開啟時的 Gatekeeper 警告

因為應用程式沒有經過 Apple Developer ID 簽署，第一次開啟會跳出警告：

> 「PikminGPS」無法打開，因為 Apple 無法檢查它是否包含惡意軟體。

**解除方法（只需做一次）：**

1. 開啟「**系統設定**」→ 左側「**隱私權與安全性**」
2. 捲到最下方，找到「**已封鎖「PikminGPS」**」的訊息
3. 點擊「**仍要打開**」
4. 跳出確認對話框後按「**打開**」並輸入 Mac 登入密碼

> 之後每次開啟都不會再跳警告。

## 首次啟動

1. 從 Launchpad 開啟 **PikminGPS**
2. 預設瀏覽器會自動打開 `http://localhost:9527`
3. 左邊是地圖，右邊是控制面板

> 如果瀏覽器沒有自動開啟，手動打開 Safari 或 Chrome，輸入 `http://localhost:9527`。

### 關閉應用

直接按 **Cmd + Q** 結束 PikminGPS。iPhone 的 GPS 會在短時間內自動恢復真實定位。

## 連接 iPhone

### USB 連線（iOS 14 ~ 16）

1. 用 USB 線將 iPhone 接上 Mac
2. iPhone 彈出「信任此電腦？」時點選「**信任**」
3. 在網頁右側面板，連線方式選擇 **USB**
4. 點擊「**連接 iPhone**」
5. 選擇你的裝置，完成連接

### iOS 17 以上：先按「啟動 iOS 17+ 通道」

iOS 17 起，Apple 將裝置除錯通道改為需要 root 權限的網路通道。PikminGPS 將這個步驟整合進介面：

1. 在「**裝置**」區塊點擊「**啟動 iOS 17+ 通道**」
2. macOS 跳出系統密碼框，標題為「PikminGPS 需要管理員權限以啟動 iOS 17+ 連線通道」
3. 輸入 **Mac 登入密碼** 後按「**好**」
4. 按鈕變成「**iOS 17+ 通道已啟動**」並停用
5. 接著就可以正常按「**連接 iPhone**」

> 通道會在背景持續運行，直到你登出或重新開機。再開 PikminGPS 時若通道仍在跑，按鈕會自動顯示為已啟動狀態。

### WiFi 連線

1. 確認 iPhone 和 Mac 在 **同一個 WiFi 網路**
2. iPhone 必須事先透過 USB **配對過**此 Mac
3. iOS 17+ 同樣需先啟動通道（見上）
4. 連線方式選擇 **WiFi**
5. 點擊「**連接 iPhone**」

### 連線成功

面板上會顯示裝置資訊，例如：

```
iPhone 15 Pro | iOS 17.4 (Tunnel+DVT)
```

## 功能說明

### 1. 傳送定位

在「**傳送**」區塊：

- **座標輸入框**：輸入目標座標，格式為 `緯度, 經度`（例如 `25.033000, 121.565400`），按 Enter 或點擊「傳送」
- **地圖點擊**：直接在左側地圖上點擊任意位置，GPS 會立即傳送到該點
- **拖曳標記**：拖動地圖上的紅色標記點來移動位置

### 2. 搖桿移動

畫面右下方的「**搖桿**」區塊提供即時方向控制：

- **滑鼠拖曳**：按住搖桿圓球，向任意方向拖曳
- **鍵盤方向鍵**：按住 ↑ ↓ ← → 方向鍵移動
- 搖桿拉得越遠，移動幅度越大
- 移動速度受「速度」設定影響
- 放開搖桿或方向鍵後停止移動

### 3. 我的最愛

儲存常用地點，方便快速切換：

- **儲存目前位置**：點擊後輸入名稱，當前座標會被儲存
- **快速前往**：在列表中**雙擊**某個最愛地點，即可傳送到該座標
- **刪除**：先在列表中點選一個項目（單擊選取），再按「刪除」

> 我的最愛會儲存在 `~/Library/Application Support/PikminGPS/favorites.json`，更新 .app 或重灌後仍保留。

### 4. 速度控制

控制搖桿移動和路線行走的速度：

| 預設 | 速度 |
|------|------|
| 步行 | 5 km/h |
| 慢跑 | 8 km/h |
| 跑步 | 12 km/h |
| 騎車 | 20 km/h |
| 開車 | 60 km/h |

- 從下拉選單選擇預設速度
- 或在右邊數字框中手動輸入（範圍 0.5 ~ 120 km/h）
- 行走中途也可以即時調整速度

### 5. 導航路線 (OSRM)

使用 OSRM 公開路線服務，規劃沿著實際道路的行走路線：

**步驟：**

1. 點擊「**導航規劃**」進入設點模式（按鈕變綠色）
2. 在地圖上**依序點擊**路徑點（顯示為 A、B、C...）
3. 至少設定 **2 個**路徑點
4. 點擊「**停止設點**」結束設定
5. 點擊「**規劃路線**」— 系統會查詢 OSRM 取得實際道路路線
6. 地圖上顯示綠色路線，面板顯示總距離和預估時間
7. 點擊「**開始行走**」— GPS 會沿著路線自動移動

**控制：**

- 「**停止行走**」：暫停行走
- 「**清除導航**」：清除所有路徑點和路線
- 「**循環路線**」：勾選後，走完會從頭再走
- 「**⊕**」按鈕：將地圖視角拉回目前位置

### 6. 匯入 GPX

從 GPX 檔案匯入路線（支援 Strava、Google Earth、komoot 等匯出的 GPX）：

1. 點擊「**匯入 GPX**」
2. 選擇 `.gpx` 檔案
3. 路線會自動載入地圖並顯示距離資訊
4. 點擊「**開始行走**」沿匯入路線移動

> GPX 支援 `<trk>`（軌跡）、`<rte>`（路線）、`<wpt>`（航點）三種格式。

### 7. 手動路線

不使用道路規劃，直接在地圖上繪製直線路線：

1. 點擊「**繪製路線**」進入繪製模式
2. 在地圖上依序點擊路徑點（藍色圓點，用虛線連接）
3. 至少設定 2 個路徑點
4. 點擊「**完成路線**」結束繪製
5. 點擊「**開始**」開始沿路線移動

- 「**重新繪製**」：清除現有路線並重新繪製
- 「**停止**」：停止行走
- 「**循環路線**」：勾選後循環行走

### 8. 金盆模式（Pikmin Bloom）

專為 **Pikmin Bloom 拉金盆**設計：把 GPS 瞬間瞬移到 A 點（花苞點）讓遊戲讀到，然後立刻還原真實 GPS。

**操作流程：**

1. 在「**A 座標**」欄位填入金盆點座標（或先到實際 A 點按「**使用目前位置**」自動填）
2. 手動飛到金盆點，點開花苞
3. **等待「在特殊花朵上往下滑動就能獲得獎勵」提示出來**
4. **再等 2 秒**
5. 按「**拉金盆**」
6. 系統瞬間將 iPhone 定位推到 A，然後立刻停止模擬恢復真實 GPS
7. 完成 — 此時應該已經拉到金盆

> 👁 按鈕可隱藏 / 顯示座標欄位內容（直播時避免被看到）。

### 9. 日夜地圖自動切換

系統會根據目前模擬位置的經緯度和實際時間，自動判斷該地點是白天還是夜晚：

- **白天**：使用 OpenStreetMap 標準亮色地圖
- **夜晚**：自動切換為 CartoDB 暗色地圖

每 60 秒自動檢查一次，傳送到不同時區的位置後也會即時更新。

## 常見問題

### Q: 第一次開啟跳出「Apple 無法檢查它是否包含惡意軟體」？

正常現象——應用程式未經 Apple Developer ID 簽署。到「系統設定 → 隱私權與安全性」最下方按「仍要打開」即可（只需做一次）。詳見[安裝章節](#第一次開啟時的-gatekeeper-警告)。

### Q: 瀏覽器沒有自動開啟？

手動打開 Safari 或 Chrome，輸入 `http://localhost:9527`。

### Q: 點擊「連接 iPhone」後沒有反應？

- 確認 USB 線已連接，且 iPhone 上已點選「信任此電腦」
- **iOS 17+ 必須先按「啟動 iOS 17+ 通道」**並輸入密碼
- 連線方式試試切換 USB / WiFi / 自動

### Q: 按「啟動 iOS 17+ 通道」沒反應或失敗？

- 密碼框跳出但取消或輸入錯誤 → 直接再按一次按鈕重試
- 連續失敗 → 重新開機後再試
- 仍然失敗 → 可在終端機手動啟動：`sudo python3 -m pymobiledevice3 remote tunneld`（需先 `pip3 install pymobiledevice3`）

### Q: WiFi 連線找不到裝置？

- iPhone 和 Mac 必須在同一個 WiFi 網路
- iPhone 需要事先透過 USB 配對過此 Mac
- iOS 17+ 通道啟動後需要等待約 5~10 秒才能發現 WiFi 裝置

### Q: 傳送位置後 iPhone 上沒有變化？

- 確認面板上顯示「已連接」狀態
- 開啟 iPhone 上的 Apple Maps 或 Google Maps 確認位置是否改變
- 某些 App 可能會使用自己的定位邏輯，需要重新開啟 App

### Q: 拉金盆失敗 / 沒拉到？

- 確認已連接 iPhone（面板顯示「已連接」）
- 「在特殊花朵上往下滑動就能獲得獎勵」提示出來後**至少等 2 秒**再按拉金盆
- A 座標必須是真實 A 點（你目前位置）的座標，不是金盆點座標

### Q: 如何恢復 iPhone 真實 GPS？

- 點擊「**停止模擬**」按鈕
- 或直接重新啟動 iPhone
- 關閉 PikminGPS 後，iPhone 在一段時間內也會自動恢復

### Q: 瀏覽器中地圖沒有顯示？

- 確認 Mac 有網路連線（地圖磚需要從網路載入）
- 嘗試重新整理頁面（Cmd + R）

## 開發者：從原始碼執行

如果你想修改程式碼或從原始碼啟動：

### 依賴

```bash
brew install python3
cd PikminGPS-Web
chmod +x start.sh
./start.sh
```

`start.sh` 會自動建立 venv、安裝依賴、啟動 Flask 伺服器（port `9527`）。

### iOS 17+ tunneld（開發模式）

開發模式下沒有自動啟動按鈕，需手動：

```bash
sudo python3 -m pymobiledevice3 remote tunneld
```

### 重新打包成 .app + DMG

```bash
source venv/bin/activate
pyinstaller --noconfirm PikminGPS.spec

# 製作 DMG
STAGE=$(mktemp -d)
cp -R dist/PikminGPS.app "$STAGE/"
ln -s /Applications "$STAGE/Applications"
hdiutil create -volname "PikminGPS" -srcfolder "$STAGE" -ov -format UDZO PikminGPS.dmg
rm -rf "$STAGE"
```

## 注意事項

- 本工具僅供 **開發測試** 和 **學習研究** 使用
- 模擬 GPS 定位可能違反某些 App 的使用條款
- iOS 17+ 通道一旦啟動會持續運行直到登出 / 重開機
- 每次重新連接 iPhone 後，需要重新點擊「連接 iPhone」
- 錯誤日誌：開發模式存於專案根目錄 `error.log`
